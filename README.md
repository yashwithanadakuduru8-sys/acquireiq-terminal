# AcquireIQ: Institutional M&A Intelligence Terminal

> **Autonomous due diligence and integration debt forensics for high-stakes corporate acquisitions.**

## 💡 The Problem
Mergers and acquisitions (M&A) fail not because of poor financial strategy, but because of **hidden integration debt**—undocumented technical debt, clashing codebases, and cultural silos buried across thousands of pages of unstructured data rooms. Traditional manual audits are too slow and miss critical red flags.

## 🚀 The Solution: AcquireIQ
AcquireIQ is an institutional-grade M&A Intelligence Terminal designed to ingest target company assets, map them into a persistent vector memory (`Hindsight DB`), and run autonomous multi-agent code and culture audits before term sheets are signed.

---

## 🛠️ Architecture & Frontend Engineering
Because this repository represents our high-performance prototype submission, we focused heavily on world-class frontend architecture and system design rather than bloated template frameworks:
- **Zero Dependencies:** Built as a pure, lightning-fast, self-contained web interface.
- **Mathematical Viewport Scaling:** Utilizes custom CSS scaling math (`--u`) mapped to a locked coordinate grid to ensure zero layout shift across devices.
- **GPU-Accelerated Glassmorphism:** Custom multi-stop linear gradients paired with backdrop filters for a high-end data terminal aesthetic.
- **Interactive Terminal Mock:** Built-in secure session initialization simulation for live judge walkthroughs.
